A clothing modification for **!Ω Factorial Omega: My Dystopian Robot Girlfriend (MDRG)** adding a stylish baggy hoodie / leather jacket outer layer for your robot companion.

---

## 🎮 Features

- **Upper Outer Layer:** Equips to the `UpperBodyOuter` slot with hoodie controller support.
- **Dual Color Customization:** Includes customizable palette slots for base color and drawstring color (`Color base`, `Color de la cuerda`).
- **Scene Textures:** Full scene coverage across all positions and interactions.
- Compatible with MDRG version **v0.97.12** (Target: `0.90.6`).

---

## ⚙️ Mod Type

This is an **Internal Mod**, designed to be imported, enabled, and managed directly using MDRG's built-in in-game mod manager (available on PC, Mac, and Android). It does not require external modding tools or loaders such as LemonLoader.

Ready-to-use mod packages are available under the [**Releases**](https://github.com/MDRG-MODS/full-metal-jacket/releases) tab.
