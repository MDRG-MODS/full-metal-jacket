A clothing modification for **!Ω Factorial Omega: My Dystopian Robot Girlfriend (MDRG)** adding a stylish baggy hoodie / leather jacket outer layer for your robot companion.

---

## 🎮 Features

- **Upper Outer Layer:** Equips to the `UpperBodyOuter` slot with hoodie controller support.
- **Dual Color Customization:** Includes customizable palette slots for base color and drawstring color (`Color base`, `Color de la cuerda`).
- **Scene Textures:** Full scene coverage across all positions and interactions.
- Verified 100% working on MDRG version **v0.97.12** (Target: `0.90.6`).

---

## 📥 Installation

1. Go to the [**Releases**](https://github.com/MDRG-MODS/full-metal-jacket/releases) page and download `fullmetaljacket.zip`.
2. Navigate to your MDRG installation directory:
   ```text
   .../My Dystopian Robot Girlfriend/FactorialOmega_Data/StreamingAssets/Mods/
   ```
3. Extract `fullmetaljacket.zip` into your `Mods/` directory so that `mod.json` is located at:
   ```text
   .../StreamingAssets/Mods/fullmetaljacket/mod.json
   ```
4. Launch the game and obtain the item in-game.
